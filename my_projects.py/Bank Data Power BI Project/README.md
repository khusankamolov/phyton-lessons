# Ipak Yo‘li Bank — Financial & Operational Analytics Dashboard

A **Power BI Business Intelligence and Analytics solution** developed to provide an interactive view of **financial performance, customer activity, and banking operations**.

The project transforms banking data into clear dashboards and KPIs, helping users identify trends, compare performance, and support data-driven decision-making.

---

## 📊 Dashboard Overview

The report consists of several analytical views:

### 💰 Financial Overview
- Revenue and operating costs
- Net profit and margins
- Financial performance trends
- Key financial KPIs

### 👥 Customer Analytics
- Customer portfolio growth
- Deposits and loan distribution
- Customer activity
- Product and service adoption

### 💳 Transaction & Operations
- Transaction volume and value
- Daily and monthly transaction trends
- Channel utilization
- Operational performance

### 🎨 Custom UI/UX

The dashboard uses a custom design inspired by **Ipak Yo‘li Bank's corporate identity**, with consistent branding, interactive slicers, KPI cards, and structured layouts for intuitive navigation.

---

## 🛠 Tech Stack

- **Power BI Desktop** — dashboard development and visualization
- **DAX** — KPIs, calculated measures, and time-intelligence
- **Power Query (M)** — data cleaning and transformation
- **Star Schema** — scalable and performance-oriented data modeling

---

## 🏗️ Data Model

The solution follows a **Star Schema** architecture consisting of fact and dimension tables.

The model is designed to support efficient filtering, aggregation, drill-down analysis, and time-based performance comparisons.

Power Query is used for the ETL process, including data cleaning, transformation, validation, and preparation for analysis.

# Netflix Content Analytics Dashboard

An interactive one-page Power BI dashboard for analyzing Netflix movies and TV shows through ratings, genres, countries, and audience engagement.

## Dashboard Preview

![Netflix Dashboard](images/dashboard.png)

## Project Overview

This project explores Netflix's content catalog using Power BI.

The dashboard provides an interactive overview of Movies and TV Shows, with a focus on content distribution, ratings, genres, countries, and audience votes.

## Key Metrics

- Total Movies & TV Shows
- Movies vs. TV Shows
- Average Rating
- Total Votes
- Votes per Title
- Number of Titles by Rating Group

## Analysis

The dashboard includes:

- **Content Overview** — comparison of Movies and TV Shows
- **Rating Analysis** — distribution of titles across rating groups
- **Genre Analysis** — average rating and number of titles by genre
- **Country Analysis** — titles, ratings, and votes by country
- **Audience Engagement** — votes and votes per title
- **Title-Level Analysis** — detailed information about individual titles

## Interactivity

Users can interact with the dashboard through:

- Movie / TV Show filters
- Rating filters
- Interactive visual selections
- Dynamic calculations
- Title-level exploration

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Visualization
- Data Cleaning

## Dataset

The dashboard was built using a Netflix titles dataset.

The dataset used in the project is included in this repository.
